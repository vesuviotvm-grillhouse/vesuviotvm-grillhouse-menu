# Vesuvio Grill House – Digital Menu

## Files
- `index.html` – the mobile-friendly menu website
- `images/menu-page-1.jpg` – your first uploaded menu image
- `images/menu-page-2.jpg` – your second uploaded menu image
- `images/vesuvio-logo.jpg` – your Vesuvio Grill House logo

## Preview on your computer
1. Extract this ZIP file.
2. Open the `vesuvio-digital-menu` folder.
3. Double-click `index.html`. It should open in your browser.

## Free hosting with GitHub Pages
1. Sign in at https://github.com/ (create a free account if needed).
2. Click **New repository**.
3. Repository name: `vesuvio-menu`
4. Choose **Public**, then click **Create repository**.
5. On the repository page, choose **Add file → Upload files**.
6. Upload `index.html` and the complete `images` folder. Keep the folder structure exactly as supplied:
   - `index.html`
   - `images/menu-page-1.jpg`
   - `images/menu-page-2.jpg`
   - `images/vesuvio-logo.jpg`
7. Click **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, select **Deploy from a branch**.
10. Choose branch **main**, folder **/(root)**, then click **Save**.
11. Wait a few minutes. GitHub will show your website address, usually:
    `https://YOUR-USERNAME.github.io/vesuvio-menu/`
12. Open that address on your phone and confirm both menu images load.

## Make the QR code
1. Copy your final GitHub Pages address.
2. Open a trusted QR-code generator, such as https://www.qrcode-monkey.com/.
3. Select URL/Website and paste the GitHub Pages address.
4. Generate and download the QR code.
5. Test it with a phone camera before printing it on table cards, posters or bills.

## Important
- Do not rename or move the `images` folder or the image files unless you also update the paths in `index.html`.
- The GitHub repository must be public for the free GitHub Pages setup described above.
- If you update either menu image later, upload the replacement using the same filename and commit the change.
- QR code points to the website address, so the same QR code continues to work when you update the menu while keeping the website address unchanged.
